Café Donguri

架空カフェの紹介＋モバイルオーダーサイト

  • HTML
  • CSS
  • JavaScript
  • Responsive
  • Netlify
  • AI画像生成（Gemini）
  • AIコーディング支援（Claude）

2026.10.11 制作 ／ 制作期間：約2時間

制作のポイントを見る
ターゲット・目的
「海辺でゆったり過ごしたい20〜30代」を想定した、架空カフェの公式サイト。
写真や雰囲気でお店を選ぶ人に世界観を伝えることと、 スマホから迷わず注文できることの両立を目指しました。
工夫したポイント
【デザイン】
・「夕暮れの光」をテーマに、ベージュ×オレンジの配色と明朝体で、落ち着いた空気感を表現
・ムードボードで方向性を決めてから AI で画像を生成し、全体のトーンを統一
【使いやすさ】
・メニューの絞り込みから、カートの個数変更・合計金額の自動計算・注文完了まで、ページを移動せずに完結
・スマホでは画面下にカートバーを固定し、いつでも注文内容を確認できる導線に
・価格は実在するカフェの相場を調べて設定し、リアリティを追求
担当範囲・制作プロセス
企画・世界観の設定・デザインの方向性・メニューと価格の設計・画像生成のディレクションを担当。 コーディングは AI（Claude）の支援を受けながら、内容を理解したうえで調整・修正して仕上げました。
今後の改善
Stripe（テスト環境）を使った決済の導入と、ページを再読み込みしてもカートの中身が消えない仕組みの追加。
