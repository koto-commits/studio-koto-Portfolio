Concept

「海辺でゆったり過ごしたい20〜30代」を想定した、架空カフェの公式サイト。
写真や雰囲気でお店を選ぶ人に世界観を伝えることと、 スマホから迷わず注文できることの両立を目指しました。

Point

01　デザイン

「夕暮れの光」をテーマに、ベージュ×オレンジの配色と明朝体で、落ち着いた空気感を表現。ムードボードで方向性を決めてから AI で画像を生成し、全体のトーンを統一しました。

02　使いやすさ

メニューの絞り込みから、カートの個数変更・合計金額の自動計算・注文完了まで、ページを移動せずに完結。スマホでは画面下にカートバーを固定し、いつでも注文内容を確認できるようにしました。

03　リアリティ

価格は実在するカフェの相場を調べて設定しました。

Process

企画・世界観の設定・デザインの方向性・メニューと価格の設計・画像生成のディレクションを担当。
コーディングは AI（Claude）の支援を受けながら、内容を理解したうえで調整・修正して仕上げました。

花渡 HANAWATARI

海の見える丘にたたずむ、架空の宿のブランドサイト

使用技術
HTML / CSS / JavaScript / Netlify / Gemini（画像生成）/ Claude（AIコーディング）
サイトを見る ↗ コードを見る（GitHub）↗

Concept

「ファンタジーのような世界観なのに、日本のどこかに本当にありそう」な宿。
ひと目で世界に引き込まれ、季節ごとに訪れたくなるサイトを目指しました。

Point

01　季節の切り替え

春夏秋冬のボタンで、写真・色・舞うもの（花びら／綿毛／落ち葉／雪）・窓の灯りがまとめて変化。開いた日の季節を自動で表示します。

02　背景が固定されたまま、文章が流れる

写真を画面に固定して、その上を文章が流れていく演出で、丘や図書室にいるような没入感を表現しました。

03　高級感と、表示の軽さ

細い文字と広い字間、暗いセクションでのメリハリ、フィルムの粒子感で上品な雰囲気に。写真は軽い形式（WebP）にして遅延読み込みし、動きが苦手な人向けの設定にも対応しました。

Process

企画・世界観の設定・構成の判断・写真の生成（Gemini）とディレクションを担当。
デザインとコーディングは AI（Claude）と共同で進め、内容を確認しながら調整しました。
架空の宿のため、写真・文章はすべてオリジナルです。
